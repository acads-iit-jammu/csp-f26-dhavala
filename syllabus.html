Syllabus

This page reproduces the official course template for CS-1-01 (MO) / EFL001U1M — Computers and Programming (called Computer System and Programming in the timetable). The course is an Institute Core (Engineering Foundations) for all B.Tech. programmes.

Course Objectives

This course leads the students to understand the need of programming in various disciplines, basic concepts of algorithm, the process of computational problem solving in an efficient manner, how to write simple programs using C, pointers, dynamic memory allocation, arrays, functions, recursions, file handling and error handling, and basic concepts of modularity.

Course Outcomes

At the end of the course students will be able to:

  1. Implement a given algorithm in C by using standard programming constructs such as pointers, arrays, repetitions, functions, modules, aggregated data (arrays, lists, etc.).
  2. Explain the output of a given C program, and identify and correct errors in a given C program (debug).
  3. Write simple programs to solve math problems using the C programming language.

Course Contents

Basic information about the computer; number systems and arithmetic; C program structure; programming types; compiler, interpreter; syntax of the C programming language; data types; operators and operator precedence; conditional statements; iterative statements (for, while, do-while); pointers; dynamic memory allocation; arrays; functions; string processing; file handling; error handling; header files; structures and unions in C.

Detailed Lecture Contents (28 hours)

Topic Hours
Introduction: Introduction to Computer Science; Computer Algorithms; Computer Hardware; Computer Software 2
Number systems, conversions, and arithmetic 4
Programming types (declarative, imperative); C program structure (source files, assembly files, object files, linker, loader); compiler, interpreter 4
Data and expressions: literals, variables and identifiers, operators, expressions and data types; control structures: boolean expressions, selection control, iterative control 5
Pointers (pointer variables); arrays; dynamic memory allocation (malloc, calloc, realloc); functions and recursive functions 8
Function pointers; structure, union; file handling; error handling 3
Problem solving sessions 1
Applications; brief of object-oriented programming 1
Total lecture hours 28
