Pointer variables

A pointer stores the starting address of a memory block. Two pointers can refer to the same block.

Memory blocks

Block 1 is the original allocation. Block 2 is the replacement when realloc moves it. These labels identify blocks in this diagram; they are not C variables or actual addresses. Boxes show array elements.

Four rules to take away

  • A pointer is a variable; the allocated object has a separate lifetime.
  • malloc gives uninitialised storage. “?” means indeterminate, not zero.
  • For positive sizes, failed realloc leaves the original allocation intact. Use a temporary pointer.
  • After free or successful realloc, old aliases must not be used. Setting one pointer to NULL does not repair the others.

In C, include <stdlib.h> and write int *p = malloc(n * sizeof *p); without a cast. Check n and the allocation result before use. free(NULL) is permitted.
