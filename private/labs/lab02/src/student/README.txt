CS-1-01 (MO) · Lab 02 — First C Programs
Quickstart (full instructions: course site > Lab Sheets > Lab 02):

  1.  tar xzf lab02.tar.gz && cd lab02
  2.  ./install.sh          (then cd into the workspace it prints — ONLY work there!)
  3.  script session.txt    <- START THE RECORDER FIRST
  4.  playground first:  p1_*.c  p2_*.c  p3_*.c  (run, then tinker per the comments)
  5.  graded problems:   e1.c .. e5.c  (the spec is the comment at the top of each)
  6.  ./check.sh e1         (check one)      ./check.sh   (check everything)
  7.  ./check.sh --bundle   (then carry the bundle out with you)

Public test inputs are in each spec. The checker also draws fresh random
inputs from each GIVEN — so compute, don't memorize.
