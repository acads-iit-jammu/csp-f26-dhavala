CS-1-01 (MO) · Lab 01 — Move-In Day
Quickstart (full instructions: course site > Lab Sheets > Lab 01):

  1.  tar xzf lab01.tar.gz && cd lab01
  2.  ./install.sh              (it infers your branch, asks your roll numbers)
  3.  cd into the workspace it creates
  4.  script session.txt        <- START THE RECORDER FIRST
  5.  follow the lab sheet, mission by mission
  6.  ./check.sh                (fix FAILs until all green)
  7.  ./check.sh --bundle       (then carry the bundle out with you)

The machine is shared and forgets everything. The bundle is your work.
At home (no /home/student): the workspace is created where you run install.sh.
Useful for practice: ./install.sh --branch ee --team YOURROLL
